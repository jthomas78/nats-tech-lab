Phase 1 · Design decisions 5–7

Contribution kinds and host-owned extension points

Regions the shell owns and versions. A plugin fills a target; it never chooses where a target lives, and it cannot invent one.

Targets are {owner}/{region}/v{major}. Context objects are frozen before delivery. A plugin may declare a target that is not currently mounted — it renders nothing until that host region exists.
