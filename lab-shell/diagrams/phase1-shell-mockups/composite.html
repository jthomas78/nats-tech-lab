Dictionary POC

Reference data two ways: NATS KV as the read model vs. KV as a cache in front of a Postgres CQRS projection.

Launch demo
JetStreamKVPostgresCQRS

Intro — demos/01-dictionary/README.md

The POC evaluated three side-by-side CQRS shapes over a shipping domain with Ship and Container aggregates before settling on one: canonical projection in Postgres, with NATS KV as an eager write-through cache in front of it.

The same JetStream event handler that upserts Postgres overwrites the KV entry; a cache miss falls through to Postgres. Shapes A and C were retired once the comparison was decided.

Stream SHIPPING uses LimitsPolicy, not InterestPolicy — replay is what the write side rehydrates from.

Phase 1 mockup gate — Design decision 18.

Seven artboards covering the four states the gate names (empty, loading, active, failed) plus the contributed route/panel composition, the extension-point contract, and the plugin status surface.

Static mockups, not a clickable prototype. Chrome is copied from shared/ui-shell/app-shell.css at its real values; vessel/berth data is sample.

ACTIVE — BR-AS02, BR-AS06, BR-AS12.

fleet-ops contributes a nav group, a deep-linkable route, one topbar control scoped to the active route, and the footer strip. The shell imported none of it.

BR-AS07 — the owner of a region declares and versions its target, sets order and capacity, and freezes the context it passes. Plugins fill targets; they never choose where one lives.

Two remotes contribute into demo-catalog/details-sidebar/v1 — a target owned by a BUILT-IN feature, not the shell. This is the cross-owner case Design decision 16 requires the proof remote to exercise.

EMPTY — the neutral shell root after Design decision 15 moves the catalog to /demos. Zero contributions is a designed state, not a broken one.

LOADING — BR-AS08. Nav, router and built-ins are already live because contribution METADATA arrived from the registry; only the implementation chunk is in flight. The topbar control slot stays empty rather than reserving a false shape.

Placeholders ANIMATE: table skeletons sweep, and a reserved extension point gets a deliberately fuzzy breathing block. Motion is the signal that the shell is working rather than stalled — a static gray bar is indistinguishable from a broken render. Phases are offset so a screen of pending targets does not pulse in lockstep, and all of it stops under prefers-reduced-motion, where the text still carries the meaning.

FAILED — BR-AS04. A route failure gets a shell-owned error; the sibling panel from port-insights keeps rendering. Error summaries carry stage and cause, never credentials, tokens or registry URLs.

BR-AS13 — customs-docs is rejected on shellApiVersion before any of its code executes, and route-audit loses one contribution for claiming a reserved path while its sibling survives. Rejection is per entry, never per registry.
