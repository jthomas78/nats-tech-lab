An entry pointing anywhere else is refused when it is written, so a compromised write cannot aim the shell at an arbitrary host. Changing this list is a deployment change.

What a write does

Entry added indexed live — metadata only, no remote fetched
Entry removed or URL changed reload prompted, never applied under the user
Plugin already active keeps rendering until reload
Store unavailable built-ins still served; the shell renders

Every accepted write raises the revision and publishes on notify._platform.registry.frontend-plugins.changed.
