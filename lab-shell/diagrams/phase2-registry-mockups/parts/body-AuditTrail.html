Refusals are recorded, not just rejected

A refused write consumes no revision — the number would then lie about how many documents have existed — but it is still written here, with its cause. “Who tried to point the shell at a CDN” is a question asked after an incident, and it has no answer if only successes are kept.

The log is the event-sourced part

The plugin list itself is plain CRUD — only its current state is ever read. The write history is the piece something genuinely replays, which is the distinction this repo draws everywhere else.
