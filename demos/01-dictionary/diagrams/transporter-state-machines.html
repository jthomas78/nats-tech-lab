The three transporter state machines, and the four places they touch

A transporter row shows three statuses side by side, but they are three separate machines with three separate owners. Only four edges cross between them — everything else in the grid is independent, which is why combinations that look contradictory are usually legal. Tinted boxes are the values the operator actually sees as a badge, in the severity colour TransporterPanel.vue gives them; plain outlined boxes are internal mechanism the UI never renders.

Why the coupling is this thin on purpose

  • GIT is derived, so it can never disagree with the documents. BR-TP38 recomputes it at read time from the current GOODS_IN_TRANSIT rows — the approved certificate answers when there is one, otherwise the worst of Rejected > Expired > Pending > Active. There is no stored column to drift and no expiry job mutating document status; an expiresAt in the past simply reads as Expired.
  • Vetting gates activation but never performs it. BR-TP19 sits at the command boundary and reads the canonical Postgres projection — never the KV cache, never Temporal's Query API — so partner status does not acquire a hard runtime dependency on Temporal being reachable. A SHIPPER bypasses the check entirely.
  • The one automatic Status change is the cover lapse. Everything else in the bottom lane is operator-driven. BR-TP60–TP62 replaced a polling Temporal Schedule with a timer whose lifetime is the Vetted state — armed on entry, cancelled structurally on exit, so there is no window where the state has moved on but the timer has not.
  • There is no direct un-lapse. BR-TP63 makes a lapse a real transition rather than a gate flipped underneath an unchanged status, and renewed cover is a new document reviewed like any other — so CoverLapsed rejoins the spine through the same BR-TP26 resubmit path Rejected uses.
  • Suspension still has no enforcement consumer. BR-TP04 is honest about this: nothing in the POC yet refuses a suspended partner's bids or loads. What the lane delivers today is the guarded state machine plus BR-TP06's append-only audit trail of who suspended whom, when and why.
