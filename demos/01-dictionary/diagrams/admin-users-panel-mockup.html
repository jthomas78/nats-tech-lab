FOR REVIEW — Phase 50 · SYSTEM → Identity → Users, and the claim-permissions drill-in

Nav: today's bare accounts item moves into a new Identity eyebrow group with users, above the existing NATS group. The roster answers open question 1 by listing two kinds in one table — credential (an nsc-defined user, one row per .creds) and session (a token minted by accounts-service, which exists only while it is connected). Sessions are observed, not enumerable: nothing persists them, so an idle session has no row at all. Health reads the JWT, not the connection: valid · expiring · expired · unused (valid, zero connections).
