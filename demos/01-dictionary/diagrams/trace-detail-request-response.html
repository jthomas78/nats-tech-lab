Today's detail pane shows one flat Headers list per span, so Nats-Requestor and Nats-Responder sit in the same undifferentiated table — indistinguishable at a glance. This splits the pane in two: a requested by / responded by strip up top, then the same headers classified into Request and Response columns underneath. Body stays a single section, since natstrace still only ever captures the reply payload — that gap is called out rather than papered over.
