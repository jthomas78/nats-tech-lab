Server-hop spans come from NATS 2.11 message tracing in traceparent mode, which stamps your trace id onto the server's own hop events — so app spans and infrastructure hops land on one waterfall. Crossing an account boundary needs allow_trace: true on the service export and stream import, which means accounts-service has to emit it in the account JWTs it mints.
