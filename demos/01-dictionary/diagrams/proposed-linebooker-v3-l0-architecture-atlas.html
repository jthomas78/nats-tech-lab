Proposed Linebooker V3 Architecture · LB-V3-L0-01 · Level 0

Architecture Atlas

A graphical table of contents for the Linebooker V3 architecture. Start here to find the smallest diagram that answers a question: L1 establishes the stakeholder landscape, L2 explains the logical construction, L3 isolates architectural concerns, and L4 records implementable designs.

PURPOSE

L0 is an architecture atlas. It is a graphical table of contents and document-status map, not a technical architecture view.

START

Begin with L1. It introduces actors, participating organisations, applications, logistics capabilities, shared platform concerns and regional placement.

ZOOM

Levels increase detail. L2 explains construction, L3 isolates one concern, and L4 provides implementable contracts and designs.

STATUS

Visual treatment carries status. Blue solid cards are available, amber solid cards are draft, and grey dashed cards are planned. A superseded state is added when a document is first replaced.

LINKS

Available cards are navigation targets. HTML cards link directly to documents; the PDF remains a distributable index with stable IDs and titles.

IDS

Stable IDs prevent ambiguity. Use LB-V3-Lx-nn when discussing, linking, superseding or reviewing a document.

SCOPE

Each document answers one primary question. New diagrams are registered here without turning L0 into a mega-diagram.

AVAILABLE

Two documents sit at L2. They branch by question, not by concern: L2-01 answers how the platform is constructed, L2-02 answers which technologies are selected and why. Splitting L2 by concern is L3's job.

Key

Green card — the atlas itself, the navigation root
Solid blue card — AVAILABLE: HTML and PDF exist and passed validation
Solid amber card — DRAFT: reviewable, not yet accepted
Dashed grey card — PLANNED: catalogued, no document yet
Coloured band — one level of the hierarchy, L1 to L4
Solid blue arrow — start here, the entry route into the set
Dashed grey arrow — zoom: the child adds detail to the parent
LB-V3-Lx-nn — the stable document ID; never renumbered or reused
No superseded cards yet — that state appears when a document is first replaced
