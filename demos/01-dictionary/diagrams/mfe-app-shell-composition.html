Micro-frontends: App Shell composition and local preview

As-built Vue micro-frontend architecture: independently served plugins are composed by the production shell and rendered in isolation by a shared development harness.

Production composition

The shell owns discovery, validation, authorization, loading, layout and errors. Plugins own their component implementation and deployment.

Development isolation

/__preview provides fast local feedback using the real plugin entry and manifest, with representative frames rather than a simulated full shell.

Transport boundary

Curated metadata and health use NATS. Federated JavaScript and chunks come from the plugin’s own HTTP origin.
