Lesson 02 — every number comes from a run you started

Today lesson 02 shows recorded tables and says "start it yourself in a terminal". This proposal gives the lesson its own log (ODOMETER_POOL, already approved in 04.8) and a Run button on every tab. The button prints the terminal command beside it, exactly the way Performance does on lesson 01. Nothing is hardcoded — a table is empty until you have run the thing it measures.

4 · Performance — four drains, one bar chart, built as they finish

Same shape as Starvation. Four runs at 1, 2, 4 and 8 workers. Each bar appears when its run ends, and the bars rescale to the slowest so far.
