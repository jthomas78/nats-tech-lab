Useful in one click. But it invites Run before the reader has read what it is aimed at.

What this does not change

  • No Go change. The server already answers both sources; -source live|bench is unchanged.
  • No business rule moves, is added or is softened. Rules stay in domain.go.
  • Nothing here reads ODOMETER (D13). Performance measures the fixture and only the fixture. The demo's own log is Showcase's job.
  • The bytes rule is untouched. ODOMETER_BENCH keeps its bytes beside its count. A row's number is one aggregate's length, not a stream's, so it carries none.
  • The tab is still read-only for the log it measures (04.7.15). Seed is still the one control here that writes.
