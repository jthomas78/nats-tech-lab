Current lab gaps and validation path

Messaging and storageThe current lab runs one NATS server; the stream factory omits replica configuration (default R1). Production needs explicit replication and recovery design. Review tenant isolation throughout persistence before pooled production.

Application boundariesAuth is currently combined in accounts-service. The diagram shows proposed responsibilities, not existing standalone services. Global authority and regional execution require deliberate application boundaries.

Local → productionCompose can validate R3 with three correctly configured NATS servers; use kind to validate Kubernetes manifests. Production may use independent Helm releases. Compose packaging alone does not provide regional HA.
