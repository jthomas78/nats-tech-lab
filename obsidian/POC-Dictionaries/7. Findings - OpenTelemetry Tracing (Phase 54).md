Findings write-up for Phase 54 — Replace `natstrace` with OpenTelemetry. Implementation detail lives in the repo (`ARCHITECTURE-COMMUNICATIONS.md` § 6, `ARCHITECTURE-OBSERVABILITY.md`, `BUSINESS_RULES-SHIPPING.md` BR-064–BR-077). The decision ledger, with the status of every decision, is in `.claude/plans/Main-POC-Plan.md` under Phase 54. This note is the stakeholder-facing *why*, and what the lab learned.

It follows [[4. Findings - Distributed Tracing (Phase 28)]]. Phase 28 built the lab's own tracer over NATS. Phase 54 removed it.

## Summary

Phase 28 sent spans over NATS: a hand-written envelope (`obs.trace.*`), a JetStream stream, a KV projection and a small bridge to Jaeger. Phase 28 also wrote down a deferred decision: use the real OpenTelemetry SDK "if this POC graduates". Phase 54 took that decision up and reversed the Phase 28 design.

Now each service uses the OpenTelemetry Go SDK through one thin shared package (`shared/otelnats`). Spans go over OTLP/HTTP to an OTel Collector with a disk queue, and Tempo stores them. Operators read traces through `observability-service` over NATS request/reply, or in Grafana. Tenants read nothing. Built 2026-10-16, checked on the au-1 cell.

## Why the lab stopped carrying spans on NATS

- **Two defects, found 2026-10-14.** Tenant spans never reached Jaeger, because the bridge read only `obs.trace.>` and tenant spans arrive as `monitor.*.trace.>`. Outbound spans carried the callee's service name, so a caller's span showed under the wrong service. Both were in code the lab owned and had to maintain.
- **Fixing them in place keeps a private tracer alive.** The standard SDK already does span creation, propagation, sampling and export. The lab's own value was small: a NATS header carrier, the tenant rule, body capture and the browser-edge rule. Phase 54 keeps only that, in one package.
- **Telemetry does not need the account model.** Phase 28 moved spans across NATS accounts with exports and imports. That made telemetry depend on tenant provisioning. Now no span crosses an account on NATS. Tenant is a span attribute, set only by the receiving service from trusted context. It is metadata and a filter, not a security boundary.

## What the lab learned

- **Durability moved, and replay was given up.** JetStream kept spans for an hour and could replay them. The Collector's disk queue now protects spans while Tempo is down. It survived a restart and a hard kill (54a). It held a peak-volume load and counted its loss when full (54b-7b). Replay to a new backend is no longer possible. No requirement asked for it.
- **Configuration is not evidence.** A full queue drained in 332 s, but Tempo's default limits dropped most of those spans. The disk queue works; delivery of a full queue to Tempo is not proved.
- **A browser must not control tracing.** A browser can send any `traceparent`, including "do not sample". Every `api.*` call now starts a new trace, and the browser's trace ID is kept only as a link (BR-071).
- **The store is swappable because the query contract is the lab's own.** Clients never call Tempo. `observability-service` answers with a versioned lab schema, so a change from Tempo to Jaeger v2 is one adapter.
- **What was lost, on purpose:** trace history from before the switch, live push in the Traces panel (it polls now), and the Pulse view until Phase 55. The Temporal hop is still not traced.

## What this does not prove

- **Production.** Tempo runs in monolithic mode on local disk. The V3 trace store is a separate V3 decision.
- **Chronicle.** The lab's design is not yet in Chronicle, the V3 codebase. A code comparison on 2026-10-16 proposed what could move. Those verdicts are proposals, recorded in the plan's ledger, not results of this phase.
- **The second cell.** za-1 was not checked.

## Stakeholder summary

- The lab's own tracer had real defects, and fixing them would have meant maintaining a tracer. The standard SDK replaced it, with one thin lab package for the parts that are specific to NATS and tenants.
- Spans no longer travel through the NATS account model. Durability now sits in the Collector's disk queue.
- The lab proved the shape. It did not prove production capacity, a full-queue delivery to Tempo, or the move to Chronicle.
